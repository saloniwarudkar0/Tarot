# Divine carate — Green Tarot Theme

A responsive React + Vite tarot website using the supplied green-and-gold tarot image as the homepage hero background and again in the Learn section.

## Run locally
1. Install Node.js (if not already installed).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal in that folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (usually http://localhost:5173).

## Customize
- Hero image: `public/images/Divine carate-green-hero.png`
- Main page: `src/App.jsx`
- Styling: `src/styles.css`

The booking CTA currently opens an email draft; connect a booking backend or form service for real bookings.
